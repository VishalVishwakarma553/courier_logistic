# Source Code & Database Ownership

**The client owns everything built for this project: source code, database, data, designs and documentation.**

| What | Owner | Where it is kept | When ownership transfers |
|---|---|---|---|
| Source code | Client | Client's own GitHub account, from day 1 | Full rights on final payment |
| Database and all data | Client | Client's own AWS account | Always the client's, from day 1 |
| Servers and hosting | Client | Client's own AWS account | Always the client's, from day 1 |
| Designs (screens, labels, invoices) | Client | Shared design files | On final payment |
| Documentation | Client | Code repository and shared folder | On handover |
| Courier, SMS, WhatsApp, payment gateway accounts | Client | Opened in the client's company name | Always the client's |
| Domain name | Client | Registered in the client's name | Always the client's |

## Terms

- **No lock-in.** Everything lives in the client's own accounts. The client can change development team at any time.
- **No licence fees.** The platform uses free open-source software. No yearly licence is payable to us or anyone else.
- **Confidentiality.** All client data, customer data and business information stay confidential. Both sides sign an NDA.
- **No reuse of client data.** We don't keep or reuse the client's data or client-specific code.
- **On handover,** all passwords and access keys are handed to the client, and the development team's access is removed or reduced to what the maintenance contract needs.
