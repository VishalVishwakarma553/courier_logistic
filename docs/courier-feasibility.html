Section 1

The short answer

Yes, the platform is feasible.

Not every courier can be fully automatic on day one, but every courier can be used through the same platform. Where a courier has no API, our system takes over that step with a manual workflow, and the customer's experience stays almost the same.

This matches the client's own requirement (§15): where the courier's API doesn't support a feature, the system must clearly show that limitation and give a manual fallback.

Section 3

What "manual" means for the customer

For a manual courier the customer still books online, gets an AWB and a label immediately, and sees tracking on the same page. The extra work is on the operations side.

StepAutomatic courierManual courier
Pincode checkLive from the courierFrom a pincode list the admin uploads in Excel
PriceOur rate engineOur rate engine (same)
AWB numberCourier gives it instantlyTaken from an AWB number series the courier gives us in advance
LabelCourier's label or oursOur system prints the label with barcode
PickupRequested automaticallyA pickup task appears for staff, who call or message the courier
TrackingAutomatic updatesThrough a tracking service if it covers the courier, otherwise staff upload an Excel file
Section 4

Courier by courier

Delhivery

Fully automatic
How to get the API
Open a business account (Delhivery One). The API token is in the client panel's API settings, or ask the account manager.
Credentials
API token, pickup location (warehouse) names, client name
Available
Pincode check, shipping cost, booking, AWB, label, pickup, tracking, cancel, failed-delivery actions. Test environment available.

Build first. This is the courier for the working demo. Each pickup address must be registered as a warehouse with Delhivery; our system can do this automatically.

Blue Dart

Fully automatic
How to get the API
Open a customer account through sales or a branch, then register on the Blue Dart API Gateway portal and link your customer code.
Credentials
Customer code, area code, login ID, license key, Client ID, Client Secret
Available
Pincode check, transit time, AWB, pickup registration, tracking, cancel. Sandbox available.

Some older Blue Dart services use an older API style (SOAP), which takes a little longer to build. COD and some products need activation on the account.

SkyKing

Likely automatic
What we found
Integration platforms list full SkyKing support: booking, label, pickup, cancel, tracking and delivery estimates. The API exists but is given to business clients privately.
How to get the API
Ask the head office, not a local franchise, for API documentation and credentials.

If they refuse: manual booking, plus automatic tracking through a tracking service.

Madhur

Likely automatic
What we found
Integration platforms list booking, AWB and label, pickup, cancel, tracking and delivery estimates. The API exists but is given privately.
How to get the API
Ask the head office IT or corporate team for API access.

If they refuse: manual booking, plus automatic tracking through a tracking service.

Shree Maruti

Partly automatic
What we found
Tracking is offered by several tracking services. No booking API was found publicly.
Plan
Ask the corporate team for a booking API. Until then: manual booking with an AWB series, and automatic tracking through a tracking service.

The Professional Couriers

Partly automatic
What we found
Tracking is covered by tracking services. No booking API was found publicly.
Plan
Same as Shree Maruti: ask for a corporate API, meanwhile manual booking and automatic tracking.

Shree Anjani

Mostly manual
What we found
No official API. Only third-party tracking services list Shree Anjani.
Plan
Full manual workflow: uploaded pincode list, AWB series, our own labels, pickup tasks for staff, and tracking through a tracking service if reliable, otherwise Excel updates.

Still ask: even a daily Excel tracking file from their head office can be imported automatically.

DHL Express

Fully automatic
How to get the API
Needs a DHL Express account number. Register at developer.dhl.com and request the MyDHL API.
Credentials
API key, API secret, account number
Available
Rates, transit time, shipment and label, pickup, tracking, customs documents. Test environment available.

FedEx

Fully automatic
How to get the API
Needs a FedEx account number. Create a project at developer.fedex.com.
Credentials
Client ID, Client Secret, account number
Available
Rates, shipping and label, pickup, tracking, address validation. Sandbox available.

FedEx checks sample labels before allowing live use. Allow 1–2 weeks and start early.

UPS

Fully automatic
How to get the API
Needs a UPS account number. Create an app at developer.ups.com.
Credentials
Client ID, Client Secret, account number
Available
Rates, shipping and label, pickup, tracking.

Confirm which UPS services your account can use from India.

Aramex

Fully automatic
How to get the API
Ask your Aramex account manager for API access and documentation.
Credentials
Username, password, account number, account PIN, account entity, country code
Available
Rate calculator, shipment and label, pickup, tracking.

Skynet

Partly automatic
What we found
Tracking is covered by several tracking services and labels by one integration platform. Booking does not appear to be available through them. Some shipping software connects using an account token issued by Skynet.
Plan
Ask Skynet India whether they issue a booking API token. Until then: manual booking and automatic tracking.

Section 7

Questions to send every courier

Send these to each courier's sales or account manager when opening the business account.

  1. Do you provide an API for business customers? Please share the documentation.
  2. Which of these can be done by API: pincode check, rate and delivery estimate, booking and AWB, label, pickup request, tracking, cancellation, failed delivery (NDR) actions, COD remittance report?
  3. Do you send tracking updates to our server (webhooks), or do we need to check? Is there a limit on how often we can check?
  4. Do you provide test (sandbox) credentials before live credentials?
  5. Do we need to whitelist our server's IP address?
  6. What label format and size is required (4×6 thermal or A4)? Can we print our own label?
  7. If there is no booking API, can you give us a pre-allotted AWB number series?
  8. How is COD remitted: how often, and in what report format?
  9. Is there any charge for API access?
  10. Who is our technical contact for integration issues?

Section 9

What the client needs to do next

  1. Open business accounts with each courier. Documents usually needed: GST certificate, PAN, company registration, cancelled cheque, KYC, expected monthly volume.
  2. Send the questions in section 7 to each courier and forward the replies.
  3. Start with Delhivery. Its token is enough to begin the working demo.
  4. Open DHL and FedEx accounts early. International approvals take the longest.
  5. Choose a tracking service once the regional couriers have replied.
