# Admin Access & Deployment Documentation

What the client receives at handover so the platform can be run, managed and maintained without depending on us.

## Access

| Access | Given to | When |
|---|---|---|
| Super Admin login to the platform | Client owner | From the first demo |
| Admin logins for staff (operations, accounts, support) | Client staff | Before launch |
| AWS account (servers, database, backups) | Client owner | From day 1 (client's account) |
| GitHub (source code) | Client owner | From day 1 (client's account) |
| Domain, email, SMS, WhatsApp, payment gateway accounts | Client owner | Always in the client's name |
| All passwords and keys (password manager) | Client owner | At handover |

## Documents

| Document | For | Contents |
|---|---|---|
| **Admin user guide** | Client admin staff | Customers, couriers, rates, pickups, billing, COD, reports, users and permissions |
| **Customer user guide** | Client's customers | Booking, bulk upload, labels, tracking, wallet, invoices, support |
| **Deployment guide** | Developers | How to release updates, environments, settings, roll back |
| **Server & hosting guide** | Developers | AWS setup, monitoring, alerts, costs |
| **Backup & restore guide** | Developers | How backups work and how to restore data |
| **Courier integration guide** | Developers | How to add a new courier to the platform |
| **API documentation** | Developers | Every API of the platform, generated automatically |
| **Database guide** | Developers | All tables and what they store |
| **Troubleshooting guide** | Support / developers | Common problems and how to fix them |

## Training

| Session | For | Length |
|---|---|---|
| Admin training | Client admin and management | 2 sessions × 2 hours |
| Operations training | Pickup, tracking and support staff | 1 session × 2 hours |
| Accounts training | Billing, COD and wallet staff | 1 session × 2 hours |
| Technical handover | Client's developers (if any) | 1 session × 3 hours |

All sessions are recorded and the videos are handed over.
